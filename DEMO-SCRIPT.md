# CollegePath Demo Day Script

**Target length: about 5 minutes**

## 0:00–0:35 — Hook and Problem

“Choosing a direction after high school can feel overwhelming. Students have to explore careers while also keeping track of real next steps. CollegePath is a small planning tool that brings career exploration and a college checklist together.”

“It is a capstone demo, not a career assessment or a replacement for a counselor.”

## 0:35–1:00 — Introduce the App

Open the running application at **http://localhost:5174/**. Point out the two sections: Career Recommendations and My Checklist.

“The frontend is React with Vite. Checklist data goes through an Express API and is saved in SQLite.”

## 1:00–3:05 — Live Demo

### Career Recommendations

1. Select **Technology** and click **Find My Careers**. Briefly read one recommendation, its useful skills, and suggested next step.
2. Clear the selection, choose **Engineering**, and show the different recommendations.
3. Select **Technology + Engineering** and show how the rule-based results respond to multiple interests.
4. Clear all interests, submit again, and show the friendly prompt.

“These are predefined recommendations matched locally by selected interests. CollegePath does not call an external AI service.”

### My Checklist

1. Point out the sample pending and completed tasks. They are labeled as demo items; other existing tasks are preserved.
2. Add a task such as **“Ask my counselor about application dates.”**
3. Mark it complete and show that it moves into the Completed group.
4. Refresh the browser and point out that the task and status remain.

If time allows, show `http://localhost:3001/api/checklist` returning the saved items.

## 3:05–4:05 — Honest AI Usage Story

“The AI usage log records what I asked for, what Copilot generated, what was actually fixed, and how results were verified.”

“For the checklist, Copilot helped implement the React interface and Express/SQLite completion update. Testing exposed an error message problem when the API returned an HTML error page instead of JSON. The fix was limited to displaying a clear fallback message.”

“For career recommendations, Copilot helped create the interest categories, predefined career data, and matching rules. I tested different interests and refined the tie-break after Science results did not rank as well as expected. The recommendations are rule-based, not generated by AI.”

“The log distinguishes browser checks, API checks, persistence checks, and build/lint checks. It does not claim that a manual test happened unless it was recorded.”

## 4:05–4:40 — What’s Next

“The current scope is intentionally limited to the capstone’s core demo. Possible next steps, only after the feature freeze and instructor review, could include getting student feedback and deciding what should be improved. This version does not include accounts, personalized data separation, or deployed production hosting.”

## 4:40–5:10 — Backup Plan and Close

If the live demo fails:

1. Do not claim a failed live action succeeded. Refresh once and check that both the Vite frontend and Express backend are running.
2. Use the already-running frontend, then open `/api/health` and `/api/checklist` on port `3001` to distinguish a frontend issue from an API issue.
3. If the backend is unavailable, explain the React → Express → SQLite flow using the architecture diagram in `README.md`. Show the career recommendations if the frontend is still available.
4. Use the persisted demo items to discuss the expected checklist behavior, and clearly label it as a fallback rather than a live test.

Close with: “CollegePath helps students turn career exploration into manageable next steps. Thank you.”
